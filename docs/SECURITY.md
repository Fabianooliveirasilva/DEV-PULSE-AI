# Security

This document maps identified risks to the controls implemented, and lists known gaps honestly. It follows the OWASP Top 10 (2021) and the OWASP API Security Top 10 (2023).

## Secrets management

- No secret is committed; `.env` is git-ignored; `.env.example` contains placeholders only.
- Secrets are read from environment variables (Docker/orchestrator secrets in production). CI uses only ephemeral test credentials.
- Stored credentials are hashes (passwords: Argon2id; sessions, reset tokens, API keys: SHA-256 of 256-bit random values).
- `METRICS_TOKEN` protects `/metrics` (constant-time comparison).

## Data retention

Logs 14 days and checks 30 days by default (configurable per organisation, max 90 / 365). Incident evidence is kept with the incident. Expired sessions and used reset tokens are purged daily. See [DATABASE.md](DATABASE.md#retention).

## Known gaps and accepted risks

| Item                                     | Status                                                                                                                             |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| E-mail verification on sign-up           | Not implemented.                                                                                                                   |
| MFA / SSO                                | Not implemented (roadmap).                                                                                                         |
| Invitations for users without an account | Not implemented; admins add existing users by e-mail (this reveals to admins whether an e-mail has an account).                    |
| Account lockout                          | Rate limiting per IP only; no per-account lockout.                                                                                 |
| Webhook signing (HMAC)                   | Not implemented; recipients cannot verify origin yet.                                                                              |
| CSP on the web app                       | Security headers are set; a nonce-based CSP for Next.js is not configured yet.                                                     |
| Container image size                     | ~450 MB per backend image (Prisma CLI is pulled as a peer of `@prisma/client`); no vulnerability impact but larger attack surface. |
| Docker images                            | Built in CI; the full Compose stack has not been run end to end yet (no Docker on the development machine).                        |

## Reporting
